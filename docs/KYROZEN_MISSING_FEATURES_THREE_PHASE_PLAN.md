# Kyrozen 未实现功能三阶段实施计划

## 1. 目的与完成定义

本文以《Kyrozen 项目方案》和《Kyrozen Development Plan》为目标基线，将当前版本尚未实现、只完成数据结构、只完成后端接口、只通过单元测试或尚未经过真实用户流程验证的能力拆成三个实施阶段。

一项功能只有同时满足以下条件才算完成：普通用户能在桌面客户端发现并操作；功能连接真实后端、本地工作区或外部服务；成功、失败、取消、重试、恢复路径均有明确反馈；生成任务产生可检查的文件、提交、测试结果或硬件记录；端到端验收通过。代码中存在类、接口或页面不单独构成完成证据。

## 2. 阶段总览

| 阶段 | 优先级 | 目标 | 完成标志 |
|---|---|---|---|
| 第一阶段 | P0 发布阻断 | 跑通桌面端软件项目主流程 | 新用户可完成需求澄清、研究、规划、编码、测试、预览、Git 提交、GitHub 推送和项目恢复 |
| 第二阶段 | P1 核心完整性 | 补齐证据研究、硬件、混合项目、验证迭代和专用工作台 | 软件项目与硬件项目各有一条可重复的真实验收流程 |
| 第三阶段 | P2 产品化 | 补齐学习、隐私、安全发布、会员和扩展能力 | 达到公开 Beta 的可安装、可恢复、可控制、可持续改进标准 |

## 3. 第一阶段：软件项目完整链路

### 3.1 专用 Agent 路由与交接

**具体缺失**

- 桌面 Python Runtime 固定创建 `BaseAgent`，任务参数中的阶段和模式没有决定实际 Agent 类型。
- 软件开发、硬件开发、测试验证和学习复盘请求不能保证由对应专用 Agent 执行。
- Agent 切换时没有结构化交接，无法稳定保留已确认目标、非目标、决策、风险和未完成任务。
- 专用 Agent 初始化失败时可能退回通用执行，用户看不到能力降级原因。

**必须交付**

1. 建立唯一 `AgentRouter`，根据项目阶段、项目类型、用户意图和本地能力选择 Agent。
2. 明确支持问题探索、市场调研、产品定义、方案设计、软件开发、硬件开发、测试验证、迭代改进、学习复盘九种模式。
3. 每次路由保存 Agent 名称、路由理由、可用工具和受限工具。
4. 阶段切换时保存结构化交接摘要；初始化失败时进入只读模式并展示修复办法。

**验收**：九种路由均有测试；开发任务记录显示软件开发 Agent；退出并重开后不重复询问已经确认的问题。

### 3.2 阶段门禁与真实进度

**具体缺失**

- 桌面端没有完整的“进入下一阶段”“返回上一阶段”“带风险推进”操作。
- 进度主要由阶段序号推导，不反映任务、Artifact、验证结果和用户确认。
- Artifact 创建、任务失败、用户确认后不会统一重新计算进度。
- 跳过必需项时没有记录跳过原因、影响、批准人和恢复条件。
- 服务端变化依赖轮询，不能可靠实时推送阶段与阻塞状态。

**必须交付**

1. 为每个阶段定义必需交付物、必需确认、必需验证和允许跳过项。
2. 进度由任务状态、交付物状态、验证结果、用户确认四部分计算。
3. 阶段检查逐条展示已满足条件和缺失条件。
4. 提供继续当前阶段、带风险推进、返回上一阶段三个动作。
5. 用事件推送任务、Artifact、阶段、阻塞和进度变化，并持久化全部状态。

**验收**：缺少 PRD 时不能无提示进入开发；任务失败后显示失败节点和修复入口；重开项目后进度完全一致。

### 3.3 真实软件生成、运行与修复

**具体缺失**

- 现有用户项目没有形成可运行产品源码，生产数据没有 `feature_implementation` Artifact。
- 技术方案、创建文件、安装依赖、启动、构建、测试、修复未被证明为连续流程。
- 生成项目没有统一 README、锁文件、环境模板、健康检查和验收命令。
- 启动或测试失败后没有稳定完成“读取错误—定位文件—修改—重跑”的闭环。
- 非编码项目没有明确的交付类型和完成标准。

**必须交付**

1. 从确认后的 PRD 生成技术方案、目录结构、里程碑和文件级任务。
2. 在项目工作区创建真实源码、锁文件、无密钥环境模板和 `.gitignore`。
3. 执行依赖安装、开发启动、生产构建、单元测试和核心流程测试。
4. 失败时关联具体任务，保存错误摘要，修改后重新运行原命令。
5. Web 产品提供可点击预览；命令行产品提供可复制命令；桌面产品提供构建产物路径。
6. 生成 README，包含目标、安装、启动、测试、配置和已知限制。
7. 生成 `FeatureImplementation`，记录需求、文件、验证命令和验证结果。
8. 为研究报告、内容方案、运营计划、业务流程设计分别建立非编码交付模板。

**验收**：普通用户创建一个真实 Web 产品；在全新目录按 README 可启动；故意制造构建失败后至少完成一次自动修复并通过原测试。

### 3.4 附件、状态、操作记录与确认

**具体缺失**

- PNG、JPEG、WebP、MP4、MOV 被当作文本读取，没有视觉分析、关键帧或语音转写。
- 附件缺少大小校验、格式校验、上传进度、失败重试、预览和删除。
- 状态行不能完整表达下载、搜索、读文件、写文件、运行测试、等待服务、等待用户和重试。
- 操作记录缺少统一开始时间、结束时间、耗时、输入摘要、输出摘要和失败原因。
- 服务端 WebSocket 确认响应尚未接入运行中 Agent 队列；重启后待确认操作不能可靠恢复。

**必须交付**

1. 图片提供缩略图、视觉分析和删除；视频提供时长、关键帧、语音转写和摘要。
2. 状态栏仅显示当前用户可理解的 Reading、Editing、Running、Searching、Waiting、Retrying 状态。
3. 最终答复上方提供可折叠操作记录，按时间展示工具动作和结果。
4. 聊天内确认提供允许一次、本项目信任此操作类型、拒绝三个选择。
5. 持久化待确认操作；应用重启后恢复卡片且不自动执行。
6. token 数、Python 安装输出、工具 JSON 和内部日志只进入诊断记录。

**验收**：图片内容能参与需求对话；短视频能产生带时间点摘要；拒绝命令后不执行；重启后确认卡仍可处理。

### 3.5 本地 Git 与 GitHub 完整流程

**具体缺失**

- 只验证了本地初始化辅助函数，没有完成新账号真实授权、建库、提交和推送验收。
- token 过期、scope 不足、取消授权、回调失败缺少完整恢复界面。
- 分支、未提交文件、最近提交和远程地址没有稳定项目视图。
- 仓库同名、远程已存在、认证失败、网络失败、非快进拒绝没有分别处理。
- 用户没有在建库前明确选择公开或私有仓库。

**必须交付**

1. 完成 OAuth 发起、浏览器授权、深链接回调、安全保存、失效识别、重新授权和主动断开。
2. 展示 GitHub 头像、登录名、scope 和连接状态。
3. 初始化主分支、`.gitignore` 和包含真实项目内容的首个提交。
4. 建库前确认所有者、仓库名和可见性；创建后设置 `origin`。
5. token 不得进入 remote URL、Git 配置、日志或项目文件。
6. 针对五种推送失败类型显示原因和恢复动作。
7. 展示分支、工作区状态、最近提交和远程链接；自动提交必须展示文件列表并可关闭。

**验收**：新账号完成私有仓库首次推送；撤销授权后客户端引导重新登录；密钥扫描零命中；第二次功能修改成功提交和推送。

### 3.6 P0 端到端发布门槛

**具体缺失**

- 当前桌面 E2E 只覆盖创建、打开画布和发送消息。
- 测试期待“采购 / Maker”“决策中心”，当前 UI 名称和结构不一致。
- 没有从安装 DMG 到完成软件产品的联合验收。
- 没有覆盖退出登录、断网、限流、任务超时、崩溃和恢复。

**必须交付**

1. 统一 E2E 与正式信息架构。
2. 覆盖首次启动、登录、建项目、探索、研究、PRD、编码、测试、预览、提交、推送、恢复。
3. 覆盖模型超时、网络中断、API 限流、工具失败、拒绝确认、磁盘写入失败。
4. 每次发布保存版本、系统、账号、项目 ID、录像、截图和结果。

**验收**：核心旅程连续三次通过；两名首次用户无需开发文档完成流程；退出后均能继续原任务。

## 4. 第二阶段：研究、硬件、验证与工作台

### 4.1 问题探索与证据管理

**具体缺失**：访谈、观察、问卷、截图、视频和公开资料没有独立结构；证据缺少可信度、时间、目标人群、反例；事实、用户观点、Agent 推断、未知信息没有稳定区分；用户不能编辑、合并、删除、标记无效或恢复证据。

**必须交付**：建立六种证据类型；保存来源、日期、人群、原文、摘要、可信度、关联问题；提供编辑、合并、删除、无效、恢复；Problem Brief 的每个关键结论引用证据 ID，并列出反对证据与未解决问题。

**验收**：六种证据均可录入和预览；删除前展示受影响结论；每个关键结论可跳转原始证据。

### 4.2 多来源市场研究

**具体缺失**：Semantic Scholar 当前实测失败；专利缺少专利号、状态、申请人；众筹缺少目标金额、结果、支持人数、交付状态；社区缺少时间、互动量、典型观点；失败来源缺少退避、配额提示和重试队列；报告不显示来源覆盖率与新鲜度。

**必须交付**

1. 论文保存 DOI、作者、年份、摘要并处理鉴权与限流。
2. 专利保存专利号、申请人、日期、法律状态、原文链接。
3. Kickstarter 与 Indiegogo 保存目标金额、已筹金额、支持人数、交付状态。
4. Reddit、Hacker News、GitHub Discussions 保存时间、互动量、观点摘要。
5. 分别展示 Web、GitHub、论文、专利、众筹、社区的成功、失败、限流、未配置状态。
6. 报告区分事实、推断、未知、正面信号、负面信号、冲突证据，并显示引用数量、来源类型和最近日期。

**验收**：一次任务取得六类来源中的至少五类；单一来源限流不阻断报告；外部事实均有可打开链接。

### 4.3 方案比较与决策门禁

**具体缺失**：不能证明稳定生成多个方案；决策页没有候选卡片、比较维度和推荐依据；拒绝推荐后没有标准重新生成路径；方案变化不分析 PRD、技术任务、采购、测试和文件影响。

**必须交付**：每个产品提供保守、平衡、激进三个方案；比较时间、成本、用户价值、技术风险、维护成本、数据风险、验证难度；展示推荐理由、关键假设、放弃内容、失败条件；支持选择、组合、重新生成；明确确认后才可开发。

**验收**：三个方案完成七维比较；组合方案同步更新 PRD 和技术方案；撤销后受影响任务停止执行。

### 4.4 硬件项目完整链路

**具体缺失**：没有真实 BOM、接线、固件、编译、上传、串口和设备行为证据；工具链安装与修复没有正式界面；板卡、端口、上传速度没有可视化确认；缺货、替代件、价格和采购状态不可操作；没有逐步装配和安全提示。

**必须交付**

1. BOM 保存精确型号、数量、单价、总价、链接、替代型号、兼容性。
2. 采购支持未购买、已下单、运输中、已到货、已检查、已安装六种状态。
3. 接线表注明两端引脚、电压、电流方向、公共地和禁止条件。
4. Maker 模式每步展示元件、动作、预期、安全提醒、照片和完成确认。
5. 检测 Arduino CLI、PlatformIO、板卡核心、串口驱动、端口并提供修复。
6. 编译、上传、串口观察保存工具版本、端口、波特率、命令和结果。
7. 上传失败区分未连接、端口占用、权限不足、板卡错误、速度过高、供电异常。

**验收**：一块真实开发板完成 BOM 到串口输出；拔插后能恢复；新手按 Maker 模式完成接线。

### 4.5 软硬件混合编排

**具体缺失**：设备协议、固件、应用、API、数据库没有统一连接模型；消息结构没有版本；离线、重复消息、重连、错误消息、版本不兼容没有测试；软件 Agent 与硬件 Agent 没有跨任务依赖。

**必须交付**：生成六层架构；定义消息字段、类型、单位、方向、频率、错误码；协议版本变化列出受影响文件；协议确认前阻止不兼容实现；提供设备模拟器；验证正常、离线、重连、重复、错误、版本不兼容六种场景。

**验收**：应用可从模拟器切换真实设备；字段变化能更新受影响文件与测试；六种场景均有记录。

### 4.6 测试、用户验证与迭代

**具体缺失**：没有 testing 或 iteration 生产项目；测试计划、用例、结果、反馈、验证报告、迭代计划没有形成链路；反馈只有通用文本；失败不能直接创建缺陷和回归任务。

**必须交付**

1. 生成需求到测试用例追踪矩阵。
2. 用例保存前置条件、步骤、预期、实际、证据、状态。
3. 软件覆盖安装、启动、核心任务、错误输入、持久化、卸载。
4. 硬件覆盖供电、输入、输出、通信、连续运行、断电恢复。
5. 用户测试保存用户类型、任务、完成情况、耗时、阻塞点、原话、满意度。
6. 失败自动创建缺陷，保存严重度、复现步骤、需求和负责人；修复后执行原用例。
7. 验证报告只能选择继续发布、修复后发布、缩小范围、停止项目四种结论。

**验收**：完成一条“失败—缺陷—修复—回归通过”闭环；至少三名目标用户进入验证报告。

### 4.7 专用项目工作台

**具体缺失**：主页缺预算、近期决策、关键风险、本周目标；决策页没有待确认队列；采购位于通用开发页；Maker 模式不存在；测试页不能执行用例或追踪缺陷；学习页不能处理建议；当前阶段的关键下一步不突出。

**必须交付**：主页展示目标、阶段、真实进度、预算、下一步、阻塞、决策、风险；决策中心展示待确认、接受、拒绝、撤销；采购中心展示 BOM、供应商、价格、数量、链接、替代件、状态；Maker 模式展示单步装配；测试中心展示矩阵、用例、缺陷、回归；改进中心提供建议操作；全部遵守 `DESIGN_SYSTEM.md`。

**验收**：用户从主页一步进入当前关键动作；七个中心分别完成真实写操作并在刷新后保留；键盘导航和窄窗口检查通过。

## 5. 第三阶段：学习、隐私、安全发布与扩展

### 5.1 学习与主动建议

**具体缺失**：没有可靠空闲调度；建议不能接受、忽略、延期、隐藏同类或删除；建议缺少证据、影响、风险、工作量；接受后不生成任务；跨项目经验不显示来源和适用条件。

**必须交付**：在空闲、阶段完成、测试失败、反馈录入后分析；建议展示原因、证据、范围、收益、风险、工作量；提供五种处理动作；接受后创建任务；跨项目经验显示来源项目、时间、原始结果、适用条件；过期建议自动失效。

**验收**：空闲分析不打断任务；接受后产生任务；忽略后不重复弹出；删除学习条目后 Agent 不再引用。

### 5.2 隐私与数据控制

**具体缺失**：用户不能查看、搜索、编辑、删除长期学习；不能关闭跨项目共享；不能标记私密项目；不能关闭空闲分析；删除项目没有分别说明云端、本地、日志、GitHub 仓库的处理。

**必须交付**：设置页增加学习数据、跨项目共享、私密项目、空闲分析、数据删除；共享默认关闭；私密项目禁止进入其他项目上下文；删除时分别选择云端记录、本地工作区、本地副本、GitHub 仓库；账号删除提供影响预览、导出、二次确认和完成凭证。

**验收**：关闭共享后其他项目检索不到内容；删除学习记录后数据库、索引、上下文均无结果；项目删除组合路径均有测试。

### 5.3 安全、诊断与恢复

**具体缺失**：确认队列未完整接通；命令风险主要依赖字符串；日志脱敏覆盖不足；长任务检查点不完整；用户不能导出脱敏诊断包。

**必须交付**：为文件写入、删除、命令、网络、Git 推送、硬件上传建立权限策略；解析可执行文件、参数、目标路径、网络目标、环境变量；防止路径穿越和符号链接逃逸；统一脱敏 token、API key、Cookie、Authorization、含凭据 URL、隐私字段；保存任务检查点；诊断包提供内容预览。

**验收**：路径攻击全部拒绝；诊断包密钥扫描零命中；编码中强制退出后可从检查点恢复。

### 5.4 正式桌面发布

**具体缺失**：DMG 没有 Developer ID 签名和公证；macOS 可能把应用移入废纸篓；自动更新开关未证明持久化和连接更新服务；缺少升级、损坏包、回滚、Intel、Apple Silicon 验收。

**必须交付**：明确采用签名公证或提供可复现的手动解除隔离政策；构建两种架构；验证首次安装、覆盖安装、卸载；持久化更新设置；实现检查、下载、校验、安装；发布说明列出功能、修复、限制、迁移、兼容性；升级前备份，失败后恢复。

**验收**：两种架构各在干净机器安装；前一版本升级后项目和工作区可用；损坏更新包被拒绝且旧版本仍可启动。

### 5.5 账号、会员与开发权限

**具体缺失**：普通账号单项目完整使用规则需要在客户端、API、数据库保持一致；开发账号无限权限缺少审计入口；Pro、Education、Team 未实现；权限变化不能即时刷新。

**必须交付**：Free 允许一个项目并开放全部阶段；只阻止第二个项目；Developer 无限项目并记录授权人、时间、原因；定义 Free、Developer、Pro、Education、Team 的项目数、成员数、存储、模型、协作权限；UI、API、数据库同时检查；角色变化事件刷新；降级不直接删除数据。

**验收**：Free 完成首个项目但不能建第二个；Developer 可建多个；直接调用 API 不能绕过限制。

### 5.6 团队、PCB、CAD 与制造交付

**具体缺失**：没有成员角色、邀请、评论、提及、任务分配、审计历史、并发冲突；没有原理图、PCB 布局、Gerber、坐标文件、CAD 源文件、STEP、尺寸图、材料、公差、供应商报价和收货验收能力。

**必须交付**

1. 支持所有者、管理员、编辑者、查看者和对应权限。
2. 支持邀请、移除、角色变更、任务指派、评论、提及。
3. 保存 Artifact、决策、任务、设置的变更人、时间、内容；并发冲突由用户选择版本。
4. PCB 包含原理图、布局、Gerber、BOM、坐标文件。
5. CAD 包含源文件、STEP、尺寸图、材料、公差。
6. 制造记录包含供应商、报价、版本、数量、交期、验收标准、收货结果。
7. 每个制造文件关联项目版本和用户批准记录。

**验收**：两名用户完成分工、评论和批准；并发修改不静默覆盖；硬件项目导出版本明确的制造包。

## 6. 跨阶段交付规则

每个功能必须同时交付用户入口、服务端接口、权限检查、数据模型、迁移、回滚说明、失败处理、恢复测试、用户说明和端到端用例。

- 第一阶段未完成时，不应称为公开 Beta。
- 第二阶段未完成时，不应宣称支持完整硬件或软硬件混合开发。
- 签名政策、隐私控制、安全恢复、账号权限未完成时，不应面向非技术用户大规模发布。
- PCB、CAD、制造、团队协作可以在公开 Beta 后单独发布，但产品页面必须明确标记为尚未提供。
